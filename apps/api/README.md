# apps/api — Quarkus backend

Modular monolith. Phase 2 skeleton: health/status, Flyway, audit persistence, storage/search ports.

```bash
./mvnw quarkus:dev
```

- API: http://localhost:8080/api/v1/health
- OpenAPI: http://localhost:8080/q/openapi
- Ops health: http://localhost:8080/q/health

See `docs/DEVELOPMENT_SETUP.md` and `docs/ARCHITECTURE.md`.
